# Upstream-Supply-Chain-Optimization - CASE STUDY

Case study on Home Depot supply and delivery chain, understanding bottlenecks and providing ideas for optimizations

Included Steps:

- Identifying Needed data
  - Exploration of data and suggesting new features
  - Data cleaning and standardization tasks
- Identification of models for use
  - K-Means Clustering
  - Association Rule Mining (ARM)
  - Time Series Models: ARIMA/LSTM
  - Regression Models: Multiple Linear Regression, Gradient Boosting Machines
  - Prescriptive modeling: Linear Programming/Mixed-Integer Programming
